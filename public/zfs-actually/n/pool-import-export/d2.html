Import and Export

concept
depth 1/3 − deeper + surface

The fear comes from RAID history: array configuration lives in a controller or an OS file, and when that dies, the disks become a puzzle. Actually, a ZFS pool's entire self-description—vdev layout, properties, dataset tree, mountpoints—lives on the member disks themselves, as labels. A dead motherboard is a hardware errand, not a data event: move the disks to any machine running OpenZFS, zpool import tank, and everything arrives—including where it all mounts.
