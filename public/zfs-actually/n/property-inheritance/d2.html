Property Inheritance

definition
depth 1/2 − deeper + surface

Every dataset carries dozens of properties—compression, recordsize, quota, mountpoint—and each one either was set here or is inherited from the nearest ancestor that set it. You don't configure datasets; you configure the tree, at the highest node where the policy is true, and let it flow down.

The small actually: there's no global config file to hunt for. The pool's root dataset is the global config, and every deviation is local, visible, and attributed.
