Snapshots, backups, and actually sleeping at night 4/6 ← prev next →

The feeling is earned: hourlies, dailies, monthlies on every dataset—you can recover anything from any point in time. That's what backups do, so surely you have backups. Actually, ask one question of any protection scheme: what failures does it survive? A snapshot lives on the same disks, in the same pool, behind the same controller, in the same building, under the same admin as the data. Pool death, fire, theft, ransomware with root, a fat-fingered zpool destroy—the snapshot dies in every scenario the word "backup" exists for.

Snapshots answer "the data changed wrongly." Backups answer "the place failed." Different questions.
