Resilvering

A disk just died 3/4 ← prev next →

A hardware RAID rebuild copies every sector, start to end, because the controller has no idea which sectors matter. Actually, ZFS is the filesystem—it knows exactly which blocks are live, so a resilver copies data, not disk ("resilvering only examines data that ZFS knows to be out of date"—zpool-scrub(8)), and verifies each block against its checksum as it goes. A half-full vdev resilvers in roughly half the time—and the time matters, because the resilver window is when your margin is thinnest.
