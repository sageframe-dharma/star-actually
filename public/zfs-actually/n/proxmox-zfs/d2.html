ZFS Under Proxmox

scenario
depth 1/3 − deeper + surface

This is how most homelabs run ZFS for years without meeting it: Proxmox offered "ZFS" at install, VMs appeared, storage worked. The naive model—VM disks are image files on a filesystem somewhere—sends you hunting for qcow2 files that don't exist. Actually, Proxmox carved each VM disk directly from the pool as a zvol (a block device, not a file), and the mysterious rpool is just the pool the installer made for the OS itself. (Operational source: the practitioner's own Proxmox Docker hosts run exactly this stack.)
