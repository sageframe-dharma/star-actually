Build your first pool with intent 9/9 ← prev next →

Guides present zpool create—the command that builds a pool—as mere setup: type it, get storage, move on. Actually, that one command makes the only decisions in ZFS you can never revise: how the disks are teamed (mirrors or RAIDZ), and the disk cell-size setting (ashift). Everything else—compression, locations, space limits, datasets—can be changed over morning coffee. The discipline is knowing which decisions are the foundation pour and giving them the ten deliberate minutes they deserve.

⚠ DESTRUCTIVE—zpool create wipes and takes over the disks you name. One mistyped disk name destroys that disk's contents. Verify with ls -l /dev/disk/by-id/ before running.
