A disk just died 2/4 ← prev next →

The instinct when zpool status shows a dead disk is either panic-speed or paralysis. Actually, a degraded pool is stable and serving—the procedure is unhurried, and the failure mode that actually bites is imprecision: pulling the wrong disk from a machine full of identical drives. The command itself is one line: zpool replace "is equivalent to attaching new-device, waiting for it to resilver, and then detaching device" (zpool-replace(8)). Everything around that line is about being sure which physical object you're touching.

⚠ DESTRUCTIVE—verify before running: zpool replace repartitions the new device, and pulling a wrong disk from a degraded RAIDZ1 or two-way mirror kills the pool. Semantics per zpool-replace(8).
